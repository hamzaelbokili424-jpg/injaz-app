إنجاز | INJAZ — نسخة أولية قابلة للنشر

مهم: هذا المشروع لم يُنشر بعد، ولا يحتوي على مفتاح OpenAI. يجب إضافة المفتاح داخل إعدادات الاستضافة فقط، وعدم وضعه في index.html أو إرساله في المحادثة.

النشر على Render:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub خاص تملكه.
2) افتح https://render.com وسجّل الدخول.
3) اختر New > Blueprint أو Web Service واربط المستودع.
4) إذا استخدمت Blueprint، سيقرأ render.yaml. وإذا أنشأت Web Service يدويًا فاختر Node، واجعل Build Command: npm install وStart Command: npm start.
5) من إعدادات الخدمة > Environment أضف OPENAI_API_KEY بقيمة المفتاح السرّي الذي تحصل عليه من حساب OpenAI الخاص بك، ثم أعد النشر. لا تضع المفتاح في ملفات المشروع ولا تشاركه مع أحد.
6) افتح الرابط العام الذي تعطيه Render واختبر /health والمدرب.

ملاحظات وحدود النسخة:
- العادات والتحديات والمحادثات محفوظة في متصفح كل مستخدم فقط، وليست حسابات متزامنة أو قاعدة بيانات مشتركة.
- حد الطلبات موجود في الذاكرة داخل نسخة الخادم، وهو حماية أولية فقط ويمكن تجاوزه في بيئة متعددة النسخ. قبل إطلاق واسع، أضف حماية أقوى ومراقبة تكاليف وحدود استخدام مناسبة.
- صفحة الخصوصية وشروط الاستخدام وتسجيل الحسابات وتخزين البيانات السحابي غير مضافة بعد. لا تجمع بيانات شخصية حساسة.
- استضافة Render المجانية قد تتوقف عند عدم الاستخدام، وتكلفة OpenAI API منفصلة وتعتمد على الاستهلاك.
